# ツイート下書きの物差し（価値観・人格系）

このファイルは、外部脳から発掘したネタを **投稿できる「有益なツイート」** に
整形するときの判断基準を定義する。tweet-draft スキルの本体が使う。

「どのネタを選ぶか」の物差しは
[../../podcast-neta/references/selection-criteria.md](../../podcast-neta/references/selection-criteria.md)
に従う（重複させない）。ここは選ばれたネタを **どう整形するか** を定義する。

## 何のためのツイートか

Podcast → note → X の流入導線のフックになるツイート。
狙うのは「バズる小手先の投稿」ではなく、
**"この人こういう人なんだ" と伝わり、共感でフォロー・保存されるツイート**。

つまり整形のゴールは、過去の自分の言葉を借りて
**オーナーの価値観・人格が一撃で伝わる一投**にすること。

## 採用する型（価値観・人格系）

過去ツイート／ノートを、次のいずれかの型に落とす。

1. **気づき・持論の言い切り**
   - 日常の一段抽象化した気づきを、断定気味に言い切る。
   - 例:「待てば待つほど美味しさは格別。効率化しすぎると、味わう権利まで手放してる気がする。」
2. **原体験の告白 → 学び**
   - 挫折・転機・恥ずかしい過去を短く開示し、そこから得た価値観に接続する。
3. **問い・違和感の投げかけ**
   - 素朴な疑問・逆張りを提示し、リスナー/読者に考えさせる。リプが付きやすい。
4. **こだわり・偏愛の表明**
   - クラフトビール・個人開発・特定作品などへの独自の視点を、熱量込みで語る。

いずれも **一人称・本人の口調**で。過去の自分の考えを、今の言葉で言い直す。

## 整形ルール

- **280 字以内**（厳守。超えたら削る）。理想は 120〜200 字（読みやすさ優先）。
- **1行目でフックを作る**。結論・意外性・問いを先頭に置く。前置きから入らない。
- **改行で"間"を作る**。一文一行を基本に、声に出して読めるリズムにする。
- **主旨を歪めない。** 元の引用の意味を保つ。言っていない主張・数字・事実を足さない。
  盛らない。過去の自分がそう考えていた範囲を超えない。
- **1ネタ最大2案**まで。言い回し・切り口の違いで出し、オーナーが選べるようにする。

## ハッシュタグ・URL・メンション

- **ハッシュタグは原則 0〜1 個。** 付けるなら文脈に本当に合うものだけ（例: #個人開発）。
  無理に付けない。羅列しない。
- **URL は原則付けない。** 告知回ではないので、価値観ツイートに宣伝リンクを混ぜない。
  note/Podcast への直接誘導が必要な回は、別途オーナーに確認してから付ける。
- **メンション（@）は付けない。**

## やらないこと（ノイズ）

- 過去の自分が言っていないことを、言ったかのように書く（捏造）。
- バズ狙いの煽り・釣り・攻撃的な逆張り。人格の信頼を損なう。
- 内輪ネタ・固有名詞頼みで、文脈がないと伝わらないもの。
- 学習ログ・作業報告・実況の"そのまま"転載。価値観に接続していないもの。

## 最終チェック（投稿前の自問）

- 280 字以内か？
- 過去の自分の主旨から**逸脱していない**か（捏造していないか）？
- これを読んだ人に **"この人はこういう価値観の人だ"** が伝わるか？
- オーナーが声に出して読んで **恥ずかしくない**（本人らしい）か？
