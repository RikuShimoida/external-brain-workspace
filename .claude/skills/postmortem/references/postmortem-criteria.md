# ポストモーテムの書き方（物差し）

オーナーの Evernote にあるポストモーテム・テンプレの各欄に「何を、どの粒度で書くか」。
テンプレ本体（見出し1〜9）はノート側にあるので、ここでは**中身の質**だけを定義する。

## 大前提：これは反省文ではなく「再発防止の設計図」

- 目的は**気持ちの整理ではなく、次に同じ状況が来たとき自動的に失敗しないこと**。
- したがって最重要セクションは **5. 原因分析** と **6. 再発防止策**。他はそこを支える材料。
- 落ち込ませない。責めない。「仕組みが悪かった」に着地させる。

## セクション別の指針

### 1. ケース
- 一行の名前。あとで一覧で見て思い出せる具体性（「ゴミ箱に痰を外した」レベルでよい）。
- 併記する: **発生日** と **失敗種別**（`ADHD` / `確認漏れ` / `思い込み` / `技術的` など）。

### 2. 概要
- 3〜5文。「いつ・何をしようとして・何が起きて・どう終わったか」。
- 損失（捨てた・払った・遅れた）まで書き切る。ここだけ読めば全体が分かる状態にする。

### 3. タイムライン
- **書ける時だけでよい**（テンプレのポイント欄に明記されている原則）。時刻が不明なら
  「前提 / 直前 / 発生時 / 直後 / 対応 / 結末」の相対ラベルで並べる。
- **「前提」の行を必ず先頭に置く。** いつもと違っていた条件は、たいていここに埋まっている。
- 分岐点（そこで別の行動を取れば防げた瞬間）が読み取れる並びにする。

### 4. 影響範囲
- 3つの軸で書く: **物的・金銭的** ／ **時間的** ／ **気分・信用への影響**。
- 仕事のケースなら「気分」を **他者への影響（迷惑・信用）** に読み替える。
- オーナーは仕事を「圧倒的でなくていい、迷惑をかけない程度」と割り切っている。
  そこに触れた失敗かどうかは重要な情報なので、素直に書く。

### 5. 原因分析
必ず2段で書く。ここを浅くしない。

- **直接的な原因**：物理的・機械的に何が起きたか。1〜2文。
- **根本原因**：なぜそれが起き得たか。**「いつもと違う前提」＋「それに気づいたのに手順を変えなかった」**
  の形に落ちることが多い。ここを「不注意だった」で終わらせない。

そのうえで、オーナー固有の**3つのレンズ**を必ず当てる（テンプレの「ポイント」欄に対応）。
分からなければ埋めずに **「要確認」と書く**。憶測で断定しない。

1. **3つ以上のことを同時にやろうとしてなかったか？**
   オーナーは「2つまでなら覚えられるが3つ以上は無理」と自覚している。
   同時並行が原因なら、対策は「減らす」一択になる。
2. **失敗種別は ADHD か？**
   ADHD 起因（記憶・注意・同時並行）なら、対策は**意志ではなく環境・仕組み**に向ける。
   そうでない（知識不足・情報不足）なら対策は別方向になるので、切り分ける意味がある。
3. **心得「自分を信用するな」で言うと、何に違反していたか？**
   これがオーナーの日々のノートの冒頭にある座右の銘。
   「覚えていられると思った」「狙って当てられると思った」「あとでやると思った」など、
   **自分の何を信用してしまったのか**を一文で特定する。ここが効く。

### 6. 再発防止策
- **意志ではなく環境を変える。**「気をつける」「次から意識する」は禁止。対策として無効。
  - 悪い例: 「次はちゃんと狙って捨てる」
  - 良い例: 「袋の縁を折り返せない＝入り口が狭いと気づいたら、そのまま使わずセットし直す」
- **狙わなくても成功する形**に寄せる。成功が精度に依存している時点で、いずれまた失敗する。
- 3〜4個まで。多く出しすぎない（実行されないなら意味がない）。

### 7. アクションアイテム
- **今すぐ着手できる具体的な物理タスク**だけ。抽象的な心構えは 6 に置いて、ここには書かない。
- 各行に **[未着手] / [進行中] / [完了]** を付ける。
- 3個まで。オーナーは3つ以上を同時に持てないので、多いなら重要な順に削る。

### 8. 学びと結論
- 3個まで。**このケースを超えて他の場面にも効く形**に一般化する。
- 「分岐点はどこだったか」を必ず1つ入れる。
- 一般化しすぎて説教にならないよう、具体語を1つは残す。

### 9. 付録
- 参照した材料（ボイスメモ、スクショ、関連ノート）。
- **関連ケース**（同系統の過去の失敗）へのリンク。同じパターンの再発は最重要のシグナル。
- **未確認事項**をここに残す。埋められなかったものを黙って消さない。

## 絶対にやらないこと

- **捏造しない。** ボイスメモ／本人の説明に無い事実（時刻・金額・登場人物・心情）を作らない。
  推測が必要な欄は空欄にせず、**「要確認」＋何を確認したいか**を書く。
- **説教しない。** 「〜すべきだった」を並べない。仕組みの話に変換する。
- **長くしない。** 全体でノート1画面〜2画面。読み返されないポストモーテムは無価値。
