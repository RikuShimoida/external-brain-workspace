# 読んだら忘れない読書術

## 一行でいうと
**本を読んでも忘れるのは「読みっぱなし」だから。** 読んでから1週間のうちに3回アウトプット（メモ・線引き・人に話す・SNSで感想）すれば、脳が「重要な情報」と判断して長期記憶に移す。だから読書は"読む"より"出す"が本体、という本。

## 概要
著者・樺沢紫苑（精神科医、年間100冊超の読書家）が、脳科学に基づく「忘れない読書」を説く本。前提は**「読んだ本＝内容を説明できる・議論できる本」**。読んだ冊数を誇っても、内容を説明できなければ読んでいないのと同じ、という厳しめの定義から始まる。

記憶のメカニズムはこう説明される。脳は入ってきた情報を1〜2週間だけ海馬に仮保存する。その仮保存期間に**2〜3回引き出された情報を「重要」と判断し、側頭葉（長期記憶）へ移す**。だから読後1週間に3回出すかどうかが、忘れる／忘れないの分かれ目になる。

読み方としては、速読一辺倒ではなく**「深読（内容を議論できるレベルまで深く）」を重視**しつつ、まず全体をパラパラ見て目的と時間配分を決める。そして**スキマ時間（通勤・待ち時間）**は制限時間効果で集中が上がる最高の読書環境だ、とする。

## 中心概念（この本の背骨）

### 1週間に3回のアウトプットで記憶に残す
本書の背骨。読後7〜10日以内に**3〜4回アウトプット**すると記憶に定着する。海馬の仮保存（1〜2週間）の間に繰り返し引き出すことで、脳が長期記憶へ昇格させるから。読んで満足して終わる人は、この窓を逃している。

### 具体的なアウトプット4段
1. **本を読みながらメモを取る／マーカーで線を引く**（読書中に出す）
2. **本の内容・気づきを人に話す、本を勧める**
3. **SNS・ブログに感想やレビューを書く**
4. **書評としてまとめる**
気軽な"一言感想"でいい。ハードルを上げると続かない。

### 「読んだ」＝説明できる・議論できる
読書のゴールは「読み終える」ではなく「内容を人に説明でき、議論できる」状態。この定義が、深く読む動機とアウトプットの必要性を同時に生む。

### スキマ時間読書と深読×速読のハイブリッド
制限時間があると集中と記憶が高まる（締切効果）。だから15分のスキマは長時間より濃い。読み方は速読一択ではなく、まず**パラパラ読み**で全体像と目的を掴み、要所は**深読**する使い分け。

## 主要な主張
1. **読みっぱなしは忘れて当然。** 記憶に残すには読後1週間で3回出す。
2. **アウトプットは軽くていい。** 線引き・メモ・人に話す・SNS感想で十分。
3. **「読んだ」の定義は"説明できる"。** 冊数ではなく、議論できる深さで測る。
4. **スキマ時間が最高の読書環境。** 制限時間が集中と記憶を上げる。
5. **速読より深読を軸に。** まず全体を掴み、要所を深く読むハイブリッド。

## 判断・行動に使える原則（相談で引く用）
相談が来たら、下から相談に効くものを**1つだけ**引いて会話に差し込む。全部並べない。

- **「読んだら1週間以内に、誰かに一言話すか、1メモ残そう」** → 忘れる悩みへの即効薬。
- **「"読み終える"じゃなく"人に説明できる"をゴールにしてみよう」** → 読んでも身につかない相談に。
- **「全部を丁寧に読まなくていい。まずパラパラ見て、要る所だけ深く」** → 積読・読むのが遅い悩みに。
- **「通勤や待ち時間の15分こそ、集中して読める最高の枠」** → 読む時間がない悩みに。
- **「線を引いた所を1つだけSNSに書く、で記憶に残る」** → アウトプットのハードルを下げる。

## この本の限界・反論（権威にしないために）
本を絶対視しないための材料。相談では「ただし…」で必ず一度は冷静側の視点を添える。

- **「3回アウトプット」を全書籍に課すと重い**。娯楽の読書や合わなかった本まで律儀にやる必要はない。刺さった本だけでいい。
- **記憶のメカニズム説明は一般向けの単純化**。「海馬2週間」「3回で長期記憶」は目安であり、厳密な数値として振りかざさない。
- **速読を軽視しすぎると、逆に大量の情報処理が要る場面で不利**。深読と速読は状況で使い分ける（→『速読トレーニング』と補完関係）。
- オーナー向けの補正：本人は**記憶を信じず外部化する人**。この本の「出して残す」は完全に一致するが、「全部の本を3回」はインプット過多になりやすい。効かせどころ（刺さった1冊）を絞る。

## 効きやすい相談テーマ
- 本を読んでも内容を忘れる／身につかない
- 積読が減らない、読むのが遅い
- インプットを発信・仕事にどう活かすか
- 読書の時間が取れない
- 何を読んだか説明できず、読んだ実感がない

## 参照すべき相談例
- 「ビジネス書を読んでも、翌週には何も覚えてない」
- 「積読が溜まる一方で、1冊も最後まで読めてない」
- 「読んだ内容を Podcast のネタにしたいけど、思い出せない」
- 「読書の時間がまとまって取れない。どうすれば読める？」
- 「読んだ本を人に説明しようとすると、うまく言えない」

## オーナーの文脈との接続メモ
- **この本の"アウトプット読書"は、このワークスペースの運用そのもの**。読んだ本の判断軸を Evernote に残し、Podcast/note で「人に説明」する＝まさに3回アウトプット。本 skill（books/volumes）に本を1冊ずつ要約している行為自体が、この本の実践になっている。
- **「読んだ＝説明できる」は Podcast のネタづくりに直結**。読書メモを"議論できる深さ"まで持っていくと、そのままひとり語りの骨組みになる。
- **記憶を信じない本人の心得と完全一致**。「読んだら忘れる前提で、すぐ外に出して残す」は本人の「自分を信用するな」の読書版。
- スキマ時間読書は、まとまった時間を確保しづらいADHD特性と相性がいい。「15分で1章＋一言メモ」を1セットにするのが合う。

## 他の本との組み合わせ
複数観点が要る相談では、独立に並べず統合する。
- **アウトプット大全 / インプット大全**（同著者）→ 読書術はこの2冊の"読書に特化した実装"。3:7・AZの読書版として一続きに語れる。
- **速読トレーニング（角田和将）**→ 「深読」と「速読」を使い分ける、で補完。読む速さ×残す深さの両輪。
- **メモの魔力**（ファクト→抽象化→転用）→ 読書メモを転用まで運ぶ工程を足せる。
- **DIE WITH ZERO**（記憶の配当）→ 読書体験も記録・言語化で何度も配当を生む、に接続。
