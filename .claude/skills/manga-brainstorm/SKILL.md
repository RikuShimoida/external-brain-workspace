# 漫画制作スキル（壁打ち〜読み切りプロットまで）

オーナー（下井田陸）は漫画原作者志望。**作画が苦手で遅筆**なので、ネームで応募できる新人賞を第一候補にしつつ、
描くこと自体は好きなので普通の新人賞も視野に入れている。

このスキルは、本人が設計した**16工程の制作フロー**に沿って、Evernote の外部脳を引きながら
「ネタ → アイデアノート → 読み切りプロット」までを一緒に進めるための型。
ネーム（紙にシャーペン）と投稿は本人の手でやる。

狙いは「新しいネタをゼロから出す」ことではなく、**すでに何度も書いている本人の芯**
（報われなかった側・記憶・殻を破る・家族への愛）を拾い直し、作品の背骨にすること。

## 大方針

- **1回に進める工程は1つ（多くても2つ）。** 16工程を一気に見せない。「今日はここ」だけ渡す。
- **勝手に突き進まない。** 探索範囲・提案・Evernote への書き込みの前は必ず一声かける。
- **冷静側の視点を必ず1つ添える。** 盛り上がっているときほど「盛りすぎ」「既視感」「実行の壁」を1点だけ差し込む。
- **一度に渡す選択肢は2択まで。** オーナーは3つ以上を同時に保持できない。分割する。
- **本人の言葉を上書きしない。** 殴り書き・シーン・キャラは本人の言葉で書く。Claude の案は「案」「叩き台」と明示し、採用されたものだけ書く。
- **ネタや引用を捏造しない。** 過去ノートの引用は必ず実在するノートに紐づける。読んでいないノートを読んだことにしない。
- 工程の詳細は [references/production-flow.md](references/production-flow.md)、
  キャラ作りは [references/character-sheet.md](references/character-sheet.md)、
  壁打ちの作法は [references/craft-principles.md](references/craft-principles.md) に従う。

## 登場するノート（Evernote）

| ノート / ノートブック | 役割 | 使う工程 |
|---|---|---|
| ノート「描きたいジャンル　目指せ2000」 | ネタの1行ストック（番号付きリスト。目標2000） | 1 |
| ノート「漫画アイデアテンプレート2」 | アイデアノート・「読み切り」ノートの型（テンプレート） | 2, 12 |
| ノートブック「漫画のアイデア」 | ネタごとのアイデアノートの置き場（約223件） | 2〜10 |
| ノートブック「〈仮の作品名〉」 | 作品化したネタの置き場。「読み切り」「読み切りプロット」ノートを入れる | 11〜14 |

テンプレート2の見出し（上から）：`自分が好きな要素` / `題材候補` / `世界観候補` / `使いたいシーン` /
`似た作風の作品（漫画、映画、小説）` / `キャラクター` / `殴り書き、メモ` / `あらすじ` / `参考URL` / `イメージソング`。
前の4つと「似た作風の作品」は**チェックリスト**（ENML の `--en-checked:true` でチェック）。
テンプレートは本人が育てているので**毎回 `get_note` で最新を取り、ID や中身をハードコードしない**。

## データソースの扱い（厳守）

詳細は [docs/data-sources.md](../../../docs/data-sources.md)。

- **Evernote には2実装がある。** 手元の対話セッションは `.mcp.json` の `evernote`（小文字）でよい。
  クラウド（Claude Code on the web）では proxy 403 で落ちるので、claude.ai コネクタ側の
  `mcp__Evernote__*`（大文字E）を `ToolSearch` でロードして使う。
  使うツール：`semantic_search` `search_notes` `get_note` `create_note` `edit_note` `create_notebook`。
- **過去ネタを探すときは「検索」と「列挙」の2経路を両方走らせる。**
  1. `semantic_search` でテーマを変えて複数回投げる（意味で拾う）。
  2. `search_notes` に `notebook:"漫画のアイデア"` を渡して**全件列挙**する（母集団の地図代わり）。
     `totalResultCount` を見て `startIndex` でページングし、取りこぼさない。
  3. 「描きたいジャンル　目指せ2000」のリストも見る（まだノート化していない1行ネタがここにある）。
- 気になったノートは `get_note` で本文（ENML）を取り、実際の言葉を拾う。

## 手順

### 0. 前提確認と現在地の判定
- Evernote が使えるか確認する。使えなければ「今日は口頭の壁打ちだけにする／手元の対話セッションでやり直す」を確認する。
- 今どこにいるかを決める。
  - **新しいネタを持ってきた** → 工程1から。
  - **既存のアイデアノート/作品名を言われた** → そのノート（とノートブック）を `get_note` し、
    [production-flow.md の「現在地の判定」](references/production-flow.md#現在地の判定途中から再開するとき) で
    最初の空欄を探して「前回は〇〇まで。今日は工程Nの△△をやりませんか？」と**1つだけ**提示する。
  - **漠然と「漫画やりたい」** → 「新しいネタを置く」か「育てかけのノートを進める」かの2択で聞く。
    後者なら「漫画のアイデア」NB を更新日順に数件見せる。

### 1. ネタを置く（工程1〜2）
- 本人のネタを1行に整え、先に**似た既出ネタ**（「目指せ2000」リスト＋「漫画のアイデア」NB）を上位数本だけ見せる。
  - **全部乗せにしない。** 世界観がぶつかるものは「キャラ/魂だけ吸収」に留める（craft-principles §6）。
- 承認を得て「目指せ2000」の末尾に1行追記 → 「漫画のアイデア」NB にテンプレート2ベースの新規ノートを作る。

### 2. アイデアノートを育てる（工程3〜10）
- 殴り書き → 好きな要素 → 題材 → 世界観 → 使いたいシーン → 似た作風の作品 → キャラ → あらすじ、の順に1見出しずつ埋める。
- チェックリストの見出しは、**殴り書きを根拠にチェック候補を提案し、本人が確定**する。
- **工程4（好きな要素）のチェック数は熱量の目安。** 少なければ「このネタは本当に描きたいカタルシスから遠いかも」と
  冷静側の一言として伝える（捨てろとは言わない）。
- キャラは荒木式身上調査書の項目で、2項目ずつ質問して埋める。
- あらすじは Claude が叩き台を書いてよいが、必ず「叩き台」と明示して本人に直してもらう。

### 3. 読み切りにする（工程11〜14）
- 作品名のノートブックを作り、その中に「読み切り」ノート（テンプレート2ベース・設定はアイデアノートから写す）を作る。
- **応募先を決めてから**あらすじを読み切りの尺に詰め直す（ネーム原作賞か通常の新人賞かでページ数が変わる）。
  応募要項は推測で書かず、必要なら公式サイトで確認する。
- 「読み切りプロット」ノートに、ページ単位・コマ割りを意識したプロットを書く（書式は production-flow.md）。

### 4. 本人の手に渡す（工程15〜16）
- ネームは本人が紙に描く。Claude は描く日の分量を1〜2ページ単位に切って渡すところまで。
- 投稿も本人。頼まれたら応募要項の確認だけ手伝う。

### Evernote への書き込み（全工程共通・承認必須）
- **書き込む前に必ず、書く場所と中身を見せて「この内容で書いていい？」と聞き、承認を得てから書く。** 勝手に書かない。
- 新規ノート：`create_note`（`notebookId` 指定、空ノートが返る）→ テンプレート2の本文を `get_note` で取り、`edit_note` で流し込む。
- 既存ノート：先に `get_note` で最新を取り、`edit_note` の `replace` は**一意になる断片**をアンカーにする。
  チェックリストは同じ語が別見出しにもある（例:「社会人」は好きな要素と題材候補の両方）ので、前後の項目まで含めて一意にする。
- ノートブック作成（工程11）は `create_notebook`。元のアイデアノートは移動しない。

### 締め（"売れそう?"ループに入らない）
- 企画は設定をいくら盛っても「売れる」の勝率は動かない。**次の一手は必ず「次の空欄」か「1話のつかみ」**に向ける
  （確証は描いた後にしか来ない）。完璧主義で動けなくなる罠に嵌らないよう、冷静に背中を押す。
- 終わるときは「今日は工程Nまで進んだ。次は工程N+1の〇〇」と**次の1手を1行で**書き残す（本人は前回を覚えていない前提）。

## braindump-to-memo との住み分け

- **manga-brainstorm**：作品の**企画・制作**そのもの → 「漫画のアイデア」NB／作品ノートブックへ。
- **braindump-to-memo**：その日の汎用の気づき/決定 → 「今日やること」ノートの**日記**欄へ。
- 漫画の壁打ちで「作品と関係ない一般的な学び/決定」が出たら、それだけ braindump-to-memo でオファーしてよい。
  企画本体を「日記」に丸ごと写す必要はない（二重管理になる）。
