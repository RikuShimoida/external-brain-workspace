# キャラクターの作り方（荒木式身上調査書）

工程9で使う。オーナーが「荒木飛呂彦の漫画術」の身上調査書を参照先として指定している
（殴り書きメモ 2026-09-25 のスクリーンショット）。以下はその**項目名だけ**を書き写したもの。

## 使い方

- **全部埋めない。** 主人公だけ深く、脇役は「基本」と「内面」の数項目で足りる。
- **一度に聞くのは2項目まで。** 下のブロックを1つずつ進める。
- 空欄の項目は Claude が勝手に創作しない。案を出すなら「案」と明示し、本人が採用したものだけ書く。
- 最後に「この作品の**好きな要素**（工程4でチェックしたもの）に、このキャラのどの項目が効いているか」を1行で確認する。
  効いていなければ、そのキャラは作品の芯とつながっていない（craft-principles §4）。

## 項目

### 基本
姓名・略称／年齢・性別／職業・学校／経済状態・その態度／ペット・植物／
生年月日・星座／血液型／出身地

### 身体
身長・体重／髪の色・目の色／視力・色力・眼鏡の有無／利き腕／声の質／
手術経験・病気・虫歯／体の傷・病気・火傷／人種・宗教／
その他の身体的特徴（鼻や目の形、姿勢、足、黒子 など）

### 経歴・内面（主人公はここを厚く）
前科・賞・学歴／幼児・少年期の精神的体験・その人物／尊敬する人・恨んでいる人／
将来の夢／恐怖／性格の特徴・口癖・癖／人間関係・態度／家族関係・態度／トラブル関係

### 性格（変わってる所）
明るいか暗いか／ユーモア・暴力的／活動・社交的か／知的か／清潔か／表現力／弱点・悩み／異常性格

### 特技・能力（長所・弱点）
動きは俊敏か／スポーツ・ダンス／武術・銃／運転／語学その他・免許

### 趣味・好き嫌い・衣食住・習慣・好きな言葉（こだわってる所・意味のない事）
音楽・新聞／文学・雑誌／映画／創作／コレクション／好きな色・嫌いな色／香り／インテリア／
ファッション／場所・家／土地／人物／贔屓の店・メーカー／愛用品／首飾り・指輪／嗜好・麻薬

### その他
ワイン・食べ物／超能力・霊感／占い・言葉鈍り／野性的カン等

## ノートへの書き方

「キャラクター」見出しの番号付きリストに、1キャラ1項目で書く。

```
1. 〈名前〉（〈年齢〉・〈職業/学校〉）
   - 恐怖：…
   - 将来の夢：…
   - 口癖・癖：…
   - 家族関係：…
```
